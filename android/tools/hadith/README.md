# الأحاديث

تُستخرج من بيانات مشروع ThaqalaynAPI (github.com/MohammedArab1/ThaqalaynAPI) المأخوذة من thaqalayn.net:

    cd ThaqalaynAPI/V1/ThaqalaynData && python3 extract_hadith.py hadith.json

من الكافي تؤخذ الأحاديث المصحّحة فقط (صحيح، حسن، موثق) حسب العلامة المجلسي، ومن معجم الأحاديث المعتبرة، ومن كتب الصدوق والأهوازي والمفيد.
